 可否说说，jensen_shannon 和 total_variation 各侧重什么？有时候排出的结果不一样                      
                                                                                                     

 可以。两者都是比较两个概率分布的距离，但关注点不同，因此排序不同是正常的。                          
                                                                                                     
 # Total Variation Distance（TVD）                                                                     
                                                                                                     
 定义：                                                                                              
                                                                                                     
 [                                                                                                   
 \mathrm{TVD}(P,Q)=\frac{1}{2}\sum_x |P(x)-Q(x)|                                                     
 ]                                                                                                   

 它衡量的是：两个分布在各个结果上的绝对概率差异总量。                                                
                                                                                                     
 直观理解：                                                                                          
                                                                                                     
 - TVD = 0：两个分布完全相同。                                                                       
 - TVD 越大：需要“搬运”的概率质量越多，才能把一个分布变成另一个分布。                                
 - 取值范围通常是 [0, 1]。                                                                           
 - 对每个类别的概率偏差直接线性累计。                                                                
                                                                                                     
 例子：                                                                                              
                                                                                                     
 ```text                                                                                             
   P: A=0.8, B=0.2                                                                                   
   Q: A=0.6, B=0.4                                                                                   
                                                                                                     
   TVD = 0.5 × (|0.8-0.6| + |0.2-0.4|)                                                               
       = 0.2                                                                                         
 ```                                                                                                 
                                                                                                     
 侧重：实际频率偏差有多大。                                                                          
                                                                                                     
 如果你更关心“指纹分布的概率比例差了多少”，TVD 通常比较直观、容易解释。                              
                                                                                                     
 ────────────────────────────────────────────────────────────────────────────────                    
                                                                                                     
# Jensen–Shannon Distance（JSD）
                                                                                                     
 Jensen–Shannon 距离基于 KL 散度。先构造中间分布：
                                                                                                     
 [                                                                                                   
 M = \frac{P + Q}{2}                                                                                 
 ]                                                                                                   
                                                                                                     
 然后计算：                                                                                          
                                                                                                     
 [                                                                                                   
 \mathrm{JSD}(P,Q)                                                                                   
                                                                                                     
 \sqrt{                                                                                              
 \frac{1}{2}D_{KL}(P\parallel M)
 +                                                                                                   
 \frac{1}{2}D_{KL}(Q\parallel M)                                                                     
 }                                                                                                   
 ]                                                                                                   
                                                                                                     
 其核心是比较两个分布携带的信息差异。                                                                
                                                                                                     
 直观理解：                                                                                          
                                                                                                     
 - JSD = 0：分布完全相同。                                                                           
 - 通常也在 [0, 1]（取决于对数底及实现）。                                                           
 - 对“低概率事件”“一个分布有、另一个没有的结果”更敏感。(事件概率低，携带信息量越大)                                              
 - 因为使用对数，概率质量在类别上的结构变化并非线性处理。                                            
                                                                                                     
 侧重：两个分布在信息结构、支持集和相对比例上的差异。                                                
                                                                                                     
 例如某个模型偶尔输出一个参考模型从不输出的特殊值，即使出现频率不高，JSD 也可能比 TVD 更明显地反映这 
 种“行为模式不同”。                                                                                  
                                                                                                     
 ────────────────────────────────────────────────────────────────────────────────                    
                                                                                                     
 为什么排序可能不同                                                                                  
                                                                                                     
 假设待识别分布是：                                                                                  
                                                                                                     
```text                                                                                             
   Observed:                                                                                         
   A=0.90, B=0.10                                                                                    
```                                                                                                 
                                                                                                     
 两个参考模型：                                                                                      
                                                                                                     
```text                                                                                             
   模型 1:                                                                                           
   A=0.80, B=0.20                                                                                    
                                                                                                     
   模型 2:                                                                                           
   A=0.90, B=0.05, C=0.05                                                                            
```                                                                                                 
                                                                                                     
 - TVD 更直接地累计概率差，可能认为模型 2 很接近：A 完全一致，只是 B 少了 0.05，多出 C 0.05。        
 - JSD 会更在意模型 2 出现了观测分布中没有的 C 这一额外行为类别，因此可能更倾向模型 1。              
                                                                                                     
 反过来，若两个候选都覆盖同一批输出值，但主要区别是常见类别的频率整体偏移，TVD 往往更符合“频率接近程 
 度”的直觉。                                                                                         
                                                                                                     
 ────────────────────────────────────────────────────────────────────────────────                    
                                                                                                     
 在 Vestigia 中如何选择                                                                              
                                                                                                     
 ### 优先使用 total_variation                                                                        
                                                                                                     
 适合：                                                                                              
                                                                                                     
 - 想得到容易解释的“概率差异量”；                                                                    
 - 各模型输出类别基本一致；                                                                          
 - 关注最常见输出的频率是否接近；                                                                    
 - 希望指标对采样噪声更直观、稳定。                                                                  
                                                                                                     
 ```python                                                                                           
   predict_distribution(                                                                             
       observed,                                                                                     
       "fingerprints",                                                                               
       distance_type="total_variation",                                                              
   )                                                                                                 
 ```                                                                                                 
                                                                                                     
 ### 优先使用 jensen_shannon                                                                         
                                                                                                     
 适合：                                                                                              
                                                                                                     
 - 希望识别罕见但有区分度的行为；                                                                    
 - 模型可能有不同的输出类别、特殊拒答、格式或身份表述；                                              
 - 更关心整体概率结构，而不只是逐项频率差；                                                          
 - 希望更重视“参考中没有、观测中出现”的新类别，或反过来的情况。                                      
                                                                                                     
 ```python                                                                                           
   predict_distribution(                                                                             
       observed,                                                                                     
       "fingerprints",                                                                               
       distance_type="jensen_shannon",                                                               
   )                                                                                                 
 ```

 实务建议                                                                                            
                                                                                                     
 可以把二者一起看，而不要只看排序：                                                                  
                                                                                                     
 1. 用 TVD 观察整体频率是否接近；                                                                    
 2. 用 JSD 检查是否有类别结构、罕见输出或支持集差异；                                                
 3. 若两者都指向同一模型，判断通常更稳；                                                             
 4. 若两者排序不同，查看该模型的 feature_matches：                                                   
     - 哪个 prompt_id 导致差异最大；                                                                 
     - 参考指纹里是否有额外输出类别；                                                                
     - params_hash="" 时，实际选中了哪份历史指纹；                                                   
     - 观测样本数是否太少，导致低频事件不稳定。                                                      
                                                                                                     
 在样本量很小的情况下，低频类别的比例波动较大，JSD 的排序尤其可能变化。此时建议增加每个 probe 的采样 
 数，再比较结果。
